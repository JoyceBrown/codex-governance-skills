# 构建与产物核验

构建动作至少区分四个身份：源码根、构建工作目录、最终产物、当前安装/运行版本。每个身份都要有路径或唯一标签，并在构建前记录预期名称、版本、平台和提交摘要。

构建后按顺序核验：

1. 退出码和关键日志摘要；
2. 产物存在、类型正确、大小非零、修改时间属于本次动作；
3. 文件名、版本、`appId`/包元数据与预期一致；
4. SHA256 或其他摘要；
5. 安装目录和运行进程是否确实引用该产物。

构建成功只证明构建器结束，不证明包可安装、包名正确、变量生效或用户路径完成。发生异常中断时先检查结果文件、锁文件、进程和半成品，再决定恢复、清理或重跑。清理属于有副作用动作，必须遵守 Guard 的授权和回滚边界。
