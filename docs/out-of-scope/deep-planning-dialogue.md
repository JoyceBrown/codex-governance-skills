# 深度规划与架构讨论不在本体系内

本体系接收已经形成的项目目标、架构结论和约束，不内置多轮深度规划、战略访谈或完整架构设计对话。此类工作可以由用户与外部模型在系统外完成，然后把结论交给 `intent-alignment`、`bootstrap-codex-project` 或项目自己的权威文件。

这是一条有意的边界，不是待补的功能缺口。深度规划的质量取决于前置讨论、领域材料和用户判断，几个固定问题不能替代完整讨论。看到仓库没有“深度访谈 Skill”时，不应因此擅自新增一个第二规划系统。

体系内允许做有限的接收和澄清：`bootstrap-codex-project` 可以收集项目基本事实，`intent-alignment` 可以把已有结论压缩为目标、可见成功状态、范围、非目标和未知。它们不能把一次简短澄清升级为完整战略规划，也不能覆盖用户或项目文件中已经确认的决定。

接收结论时保留来源、假设和未知。没有形成权威记录的讨论仍然只能作为输入线索，不能自动变成当前计划、授权或项目事实。
