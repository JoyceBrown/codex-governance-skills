# 术语表

这些词在技能之间保持同一含义。它们不是新的任务状态库。

| 词 | 含义 |
| --- | --- |
| `FOUND` | 所需上下文或证据已找回并通过一致性检查 |
| `PARTIAL` | 找回了一部分，仍有明确缺口，但可以安全交付部分结果 |
| `NOT_FOUND` | 没有找到所需上下文或证据 |
| `CONFLICTED` | 找到互相冲突的来源，不能自行选一个 |
| `BLOCKED_UNCERTAINTY` | 缺口会让继续动作扩大不确定影响，必须停止 |
| `stale` | 收据来自旧项目计划、快照、租约或会话，不能推进当前任务 |
| `unknown` | 宿主或外部动作的结果没有被可靠确认 |
| `lagging` | 可选协作者或通知暂时落后，但当前技能仍可用独立流程继续 |
| `partial` | 已完成部分可安全交付，未完成部分必须有 `next_action` |
| `blocked` | 存在明确阻断或高影响不确定性，继续会扩大风险 |
| `waiting` | 只等待有界的声明能力或外部结果，不得无限等待 |

恢复状态的完整语义唯一维护在 `skills/durable-context/references/recovery-status.md`；其他技能只引用，不另立定义。
